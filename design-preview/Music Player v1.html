功能架构

三个方向共用同一套本地优先功能骨架，不随视觉方向变化

01
本地导入
拖拽 / 选择文件 / 选择文件夹；自动解析 ID3、内嵌封面；增量扫描与去重。
02
元数据资料库
标题 / 艺术家 / 专辑 / 码率 / 采样率 / 时长表格化展示，支持排序、筛选、批量编辑。
03
播放队列
队列拖拽排序、收藏、播放历史、四种播放模式；本地不依赖任何在线服务。
04
歌词
优先内嵌歌词与本地 .lrc 导入；网易云仅作补全来源，接口失败自动静默降级。
05
网易云可选源
默认关闭；设置中显式开启搜索 / 歌词补全；所有在线请求失败都不影响本地播放。
06
系统能力
Media Session 锁屏控制、全局快捷键、倍速播放；频谱 / 均衡器作为后续增强项。
下一步：请选择方向（A / B / C，也可混搭）。
  • A = 功能优先、克制工具感，最贴合“强大播放器”的定位；
  • B = 与站点博客 / 日记的纸面气质最统一，安静但有记忆点；
  • C = 最个性、最“设备化”，适合想要鲜明差异的用户。

确定方向后，我会按所选设计系统产出可点击的 v0 原型（含上传流程与空 / 加载 / 错误状态），再进入 Vue 重构。
