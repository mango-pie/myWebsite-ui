Spring Security 6 合蒸笔记

JWT 无状态签发结合 Redis 登录态，实现主动失效；过滤器链按路径挂载，避免全局过重。

摘要

本篇合并 3 个来源：官方架构文档、JWT+Redis 实践文、方法级鉴权章节。聚焦 FilterChain 组装与会话失效策略。

要点

  • Token 与会话解耦，退出即删 Redis key
  • SecurityFilterChain 按路径拆分，优于单一全局链
  • 方法安全用 @PreAuthorize 补齐接口层

金句

无状态不等于不可失效——把失效放到可撤销的侧车存储里。

示例

http.authorizeHttpRequests(auth -> auth
    .requestMatchers("/api/public/**").permitAll()
    .anyRequest().authenticated());
