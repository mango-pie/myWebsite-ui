## 推荐阅读顺序

1. 先阅读 `00-project-overview.md`，了解项目整体目标、架构和阶段安排。
2. 按 V1 到 V4 顺序开发，优先保证项目主链路完整。
3. 核心功能完成后，再阅读 V5 扩展功能，选择适合的加分项补充。
4. 准备简历和面试时，重点阅读 `06-resume-and-interview.md`。
