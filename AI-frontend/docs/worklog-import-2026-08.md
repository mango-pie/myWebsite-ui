- [新增] 前端多平台集成：PulseTrack 增加 remoteServer/remoteId，搜索并行检索网易云 + QQ + 酷狗，播放/歌词按来源分支，刷新后自动恢复

- [修改] vite.config 增加 /meting-api 代理（dev + preview + PWA NetworkOnly）
- [修改] 两个 bat 增加 :ensure_meting 自动拉起

## 遇到的问题与解决
- 原版 Meting API 是 PHP 项目，机器无 PHP → 决定用 Node 原生 http + fetch 自研，零依赖
- 项目根 package.json 为 "type": "module"，服务端文件需 ESM 语法，否则 require 报错
- 酷狗部分域名证书不匹配（mobilecdn），换用 m.kugou.com 接口

## 总结
- 播放器从单一网易云源扩展为三源，属于"本地优先 + 多平台聚合"的合理架构
